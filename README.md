# Sakina Saifuddin — Portfolio V3

Cinematic, photorealistic vintage study-room built with **Three.js r134**.  
Interactive 3D environment: orbit, fly-to hotspots, click VHS tapes to open project panels.

**Live preview (placeholder geometry):** https://claude.ai/artifact/VjgVeoT8PVN1fUDzrL1UNy  
**V2 (live production):** https://askksakina.netlify.app

## Architecture

```
v3/
├── web/                  ← Three.js front-end (no bundler; plain ES5 + ES6 modules)
│   ├── index.html        ← Entry point: loader, canvas, HUD, nav, panel
│   ├── style.css         ← Design tokens, all components, responsive
│   ├── main.js           ← Three.js app: MinimalOrbit, flyTo, parallax, raycaster, GLB loader
│   ├── content.js        ← CONTENT global: 7 projects, skills, education, bio
│   ├── audio.js          ← Web Audio API procedural soundscape (no external files)
│   └── vendor/           ← Pinned Three.js r134 UMD build (optional local mirror)
├── assets/
│   ├── models/           ← GLB files generated by pipeline/build_model.py
│   ├── previews/         ← 320×240 Cycles preview PNGs (generated on demand)
│   ├── images/           ← Photos, logos, certificates (copied from V2 via device bridge)
│   └── resume/           ← sakina-saifuddin-resume.pdf (copied from V2)
├── pipeline/
│   ├── build_model.py    ← bpy script: builds every room element as .glb
│   └── compress_assets.sh← gltf-transform Draco + KTX2 post-compression
├── docs/
│   └── session-restore.md← How to rebuild V3 workspace in a new cloud session
└── .gitignore
```

### Camera system
- **MinimalOrbit** — custom, no OrbitControls dependency. `dampingFactor = 0.13` (V2 was 0.07).
- **Parallax** — `camera.setViewOffset()` on mousemove, cleared during fly-to tweens.
- **flyTo(view)** — cubic ease-in-out, 1350 ms, 5 hotspots: HOME · DESK · MONITOR · TV · VHS.

## Run locally

```bash
# No build step required — serve the web/ folder with any static server
cd web
python -m http.server 8080
# Open http://localhost:8080
```

Keyboard shortcuts: **H** Home · **D** Desk · **M** Monitor · **T** TV · **V** VHS rack · **Esc** back  
Touch: tap hotspots to fly; pinch to zoom; drag to orbit.

## Build 3D assets (cloud pipeline)

```bash
# Install bpy (Blender-as-a-Python-package) — cloud or local
pip install bpy==5.2.3 --break-system-packages

# Build one model and export GLB
python pipeline/build_model.py desk

# Build all models + render 320×240 preview PNGs
python pipeline/build_model.py all --preview --samples 32

# Compress GLBs with gltf-transform (needs Node.js)
npm install -g @gltf-transform/cli
bash pipeline/compress_assets.sh
```

Available models: `desk` · `monitor` · `tv` · `vhs-rack` · `chair` · `lamp` · `bookshelf` · `room-shell` · `props`

## Technology

| Layer | Choice | Why |
|-------|--------|-----|
| 3D engine | Three.js r134 (UMD, no bundler) | Zero build toolchain; phone-compatible |
| Modeling | Blender via bpy 5.2.3 pip package | Cloud-executable; no full Blender install |
| Rendering | Cycles CPU (bpy) | ~0.8 s for 320×240 preview; no GPU needed |
| Compression | gltf-transform (Draco + KTX2) | Halves GLB size post-export |
| Audio | Web Audio API, procedural | No external audio files; autoplay-policy safe |
| Hosting | Netlify (planned) | Matches V2; static; free tier |
